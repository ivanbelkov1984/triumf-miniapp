# ТРИУМФ — каталог мотосалона в Telegram

Мини-приложение Telegram для бота @TriumphMoto_bot: каталог мотоциклов, питбайков и электро, подбор за 4 вопроса, избранное, заявка Вадиму.

- Статическая сборка, сервер не нужен. Размещено на GitHub Pages.
- Персональные данные не собираются: избранное хранится в облаке Telegram пользователя, сообщения клиент отправляет Вадиму сам.
- Цены — по каталогу поставщика на дату в карточке. Информация не является публичной офертой.
- Шрифты Oswald и Inter — SIL Open Font License (assets/fonts/OFL-*.txt).

Исходники: ветка `claude/triumf-tg-miniapp-20261104` (локальный репозиторий сайта ТРИУМФ), сборка — `tools/build-miniapp-bundle.py`.
